## Nueva etapa: Análisis de energías renovables con DAX e IA

### Objetivo
Ampliar el análisis del mercado de energías renovables mediante Power BI, utilizando medidas DAX e Inteligencia Artificial para interpretar los datos y apoyar la toma de decisiones.

### Herramientas utilizadas
- Power BI Desktop.
- DAX para crear medidas y cálculos.
- Python para el análisis y la visualización de datos.
- Inteligencia Artificial como apoyo en la creación y comprensión de fórmulas.
- GitHub para almacenar y documentar el proyecto.

### Uso de Inteligencia Artificial
Se utilizaron instrucciones (prompts) para solicitar a la IA propuestas de fórmulas DAX. Posteriormente, se adaptaron al modelo de datos y a los nombres de las tablas y columnas del proyecto.

La documentación de las fórmulas se encuentra en `documentos/formulas_generadas.md`.

### Medidas DAX
El proyecto incluye diez medidas para analizar:
- Energía total comercializada.
- Costos e ingresos.
- Número de transacciones.
- Precio promedio de compra y venta.
- Energía por año.
- Margen comercial.
- Participación de energía.
- Crecimiento interanual.

### Resultados del análisis
El dashboard permite explorar el comportamiento de la energía comercializada, comparar empresas y compradores, analizar costos y precios y observar tendencias temporales.

### Aprendizajes
Este proyecto permitió fortalecer los conocimientos de Power BI, DAX, Python y el uso de Inteligencia Artificial para resolver problemas de análisis de datos.

### Reproducción del proyecto
1. Descargar o clonar este repositorio.
2. Abrir el archivo de Power BI.
3. Verificar que los archivos de datos estén disponibles.
4. Abrir el informe y explorar sus páginas y filtros.
